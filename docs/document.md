## 一、项目概述

**数字人面试**是一套面向招聘与练习场景的 **AI 数字人实时面试系统**。系统支持岗位与简历上下文感知、多轮智能问答、语音/文本双模式交互，通过 WebRTC 向浏览器端实时推送数字人面试官画面，为候选人提供沉浸式、高仿真的 AI 面试体验。

### 1.1 项目背景

传统模拟面试成本高、反馈滞后；现有 AI 面试产品大多停留在文本或语音层面，缺乏数字人形象的直观交互感。本项目基于开源数字人框架 LiveTalking，结合大语言模型（LLM）、语音识别（ASR）、语音合成（TTS）和口型驱动模型（wav2lip / musetalk），构建端到端的 AI 数字人面试平台。

### 1.2 目标用户

| 角色 | 使用场景 |
|------|----------|
| 求职者 | 上传简历、选择目标岗位，与 AI 面试官进行实时模拟面试，获取结构化面试报告 |
| 企业 HR / 招聘方 | 初筛候选人、批量化面试、查看 AI 生成的面试评估报告 |
| 高校学生 | 校招前自主练习面试，提升表达与应变能力 |

| 编号 | 需求描述 | 目标 |

| NF-006 | 安全性 | API 密钥、证书等敏感数据不进入版本控制 |

## 三、系统架构

### 3.1 技术栈

| 层级 | 技术选型 |
|------|----------|
| **前端** | 原生 HTML/CSS/JavaScript、Chart.js（雷达图）、WebRTC API |
| **后端框架** | Python aiohttp（异步 HTTP/WebSocket）、Flask（辅助） |
| **数字人驱动** | wav2lip（默认）/ musetalk / ultralight 口型模型 |
| **语音识别 (ASR)** | 腾讯云 ASR |
| **语音合成 (TTS)** | 腾讯云 TTS（默认）/ Azure TTS / 豆包 TTS / edge-tts |
| **大语言模型 (LLM)** | 阿里云 DashScope（通义千问 qwen-plus），兼容 OpenAI 接口 |
| **实时通信** | aiortc（Python WebRTC 实现） |
| **数据库** | SQLite（用户/订单数据） |
| **鉴权** | JWT（PyJWT） |
| **支付** | 微信支付 v3（wechatpayv3） |
| **简历解析** | pypdf / pymupdf / rapidocr_onnxruntime |
| **部署** | Nginx 反向代理 + HTTPS |

### 3.2 数据流

```
用户浏览器
  │
  ├─── WebRTC ────► aiohttp 服务端
  │                    │
  │                    ├── ASR（腾讯云） ──► 用户语音转文字
  │                    │
  │                    ├── LLM（DashScope）──► 生成面试问题/追问
  │                    │
  │                    ├── TTS（腾讯云） ──► 文字转面试官语音
  │                    │
  │                    └── wav2lip ──► 语音驱动数字人口型
  │                           │
  └─── WebRTC 视频流 ◄────────┘
```

### 4.2 AI 承担的任务


| AI 类型 | 在产品中的角色 | 具体任务 |
|---------|---------------|----------|
| **大语言模型 (LLM)** | 面试官智能核心 | 根据简历和岗位生成面试大纲；多轮面试对话与追问；生成结构化面试评估报告（六维评分） |

| **OCR / 简历解析 AI** | 文档理解 | 解析 PDF 简历（含扫描件 OCR），提取候选人关键信息 |
| **AI 编程助手 (Cursor/Copilot)** | 开发辅助 | 代码生成与补全、Bug 诊断、代码审查、文档撰写、Prompt 工程优化 |

### 6.3 中期可演示功能清单

1. 用户在浏览器打开面试准备页，输入目标岗位、上传简历
2. 系统自动解析简历，展示候选人画像
3. 用户选择面试官（中文/英文），点击"开始面试"
4. 数字人面试官通过 WebRTC 出现在浏览器中，进行开场白
5. 用户通过语音或文本回答，面试官根据面试大纲逐步追问
6. 面试结束后自动生成结构化面试报告，包含六维评分与雷达图

| 风险项 | 影响 | 缓解措施 |
|--------|------|----------|

| 数字人渲染 GPU 性能瓶颈 | 高延迟或掉帧 | 优化推理管线，考虑使用 ultralight 模型降低负载 |
| 腾讯云 ASR/TTS 配额限制 | 测试期间调用受限 | 提前申请配额提升，备选 edge-tts 方案 |
| 多并发会话稳定性 | 多用户同时面试可能崩溃 | 中期暂限 1 路并发，后续优化会话隔离与资源回收 |
